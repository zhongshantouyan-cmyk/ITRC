## 3. 本輪發布仍需分別核對

1. 先發布相容後端再發布新前端；新簡單流程無資料庫遷移，不默默重分類既有 18 筆活動或標成完成。回復版本須前後端配對並保留新增歷史欄位。
2. 新版 `/ops` 的實際登入、三態任務、活動與宣傳同頁、文案一次確認／取消，以及同源工具連結。虛構操作只在本機或 `/ops-demo`；隔離未確認的 Preview 保持業務唯讀。
3. 17 筆歷史看板目前只有離線預覽證據；正式套用、讀回、再次去重需由發布維護者另記，不以轉換檔存在當成已匯入。
4. AI、Canva、Sheets 的伺服器設定、OAuth 回跳、可編輯分層結果各自驗收；個人 AI 或已連接的 ChatGPT 工具不等於網站背景服務已取得憑證。人工貼稿／Canva 連結仍可使用。
5. FileOS 保持單一正式來源；提案核准、匯出包、原收件匣對照都不等於外部原檔已更新。來源修訂需核對版本並保留實際回讀證據。

## 4. 重現

使用 Node.js 22.20.0：

```bash
npm --prefix server test
node --test --experimental-test-isolation=none client/src/ops/*.test.js
node --test --experimental-test-isolation=none client/server/ops-proxy.test.mjs
npm --prefix client run build
```

本機 HTTP 測試需要允許綁定 localhost；測試資料庫與供應服務均隔離。實際伺服器啟動可能建表／遷移或執行已啟用的 worker，因此不能把程序健康檢查當成完全零寫入。Preview OIDC 只處理部署保護，Firebase 仍驗證使用者；不以 Preview 授權代替 Production 配置。
