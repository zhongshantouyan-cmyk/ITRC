## 已排入工作的背景處理

GitHub main 的 .github/workflows/ops-queue.yml 每 15 分鐘檢查最多三項已排入工作；平台觸發可能延遲。後端只接受已驗證的 GitHub 短效 OIDC：固定 issuer、JWKS、audience、repository ID／owner ID、main、workflow_ref、GitHub hosted runner 與 schedule／workflow_dispatch。排程不能建立提案、核准文案、選操作者或指定任意動作。設定缺漏及外部結果不明會停止，仍需管理者處理。

不保存新的長期排程 API key。Production 可用 OPS_GITHUB_CRON_ENABLED=false 停止；GitHub 可用 OPS_DISABLE_QUEUE=true 停止觸發。發布後必須取得一次真正 main workflow_dispatch 成功，才能宣稱連通驗收完成。

技術依據：[GitHub OIDC reference](https://docs.github.com/en/actions/reference/security/oidc)。
