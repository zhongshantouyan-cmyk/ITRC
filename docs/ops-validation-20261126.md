## 1. 操作範圍與證據來源

- 由已授權、已登入的使用者，透過既有正式工作台的 JSON 匯入介面進行兩次預覽、第一次新增與第二次重複送出。
- 透過既有完整系統備份 UI 匯出操作前、兩次預覽後、第一次新增後、第二次重複送出後的四份備份。離線驗證只讀取這些下載檔，沒有擷取瀏覽器 token、直接寫入正式 API 或正式資料庫。
- 使用 `scripts/prepare-legacy-board-import.cjs` 產生當日 payload，使用現有系統備份還原功能建立隔離副本。隔離還原核對 14 張 SQL 表、315 列與 11 個 Firebase 路徑；未連回正式環境寫入。
- 來源為 `boards/itrc`。當日備份與前一日相比，來源看板內容及版號、people、原有 tasks、events、posts 均未改變。兩次正式預覽後，另以操作前防護備份再次確認來源與目標未變。
- 公開文件只記錄筆數、驗證方法、狀態與檔案雜湊。原始備份、逐筆 mapping、操作識別碼及新增記錄識別碼保存在未納入 Git 的私密交接資料內。
